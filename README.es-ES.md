Micro Framework es un marco de ejemplo de microfrontends derivado de la guía [《深入浅出微前端》](https://juejin.cn/book/7258893482318626868).

## Características

- Basado en single-spa para su encapsulación
- Diseño de aislamiento basado en iframe
- Proporciona un mecanismo de extensión para Loader
- ...

## Instalación

``` bash
# Instalación del paquete CommonJS
npm i ziyi-micro-framework --save

# Instalación del paquete ES Module
npm i ziyi-micro-framework-es -save
```

## Guía de Contribución

Si detectas áreas de mejora en el código de este marco de microfrontends, te invitamos a señalarlas. Puedes notificarlo mediante [Issues](https://github.com/ziyi2/micro-framework/issues) o enviando un Pull Request con las correcciones. El autor revisará el código; si es aceptado, se fusionará tu contribución. De lo contrario, se te indicará el motivo de la negativa y se cerrará la incidencia.

Antes de enviar un Pull Request, asegúrate de seguir los siguientes pasos:

- Haz un fork del repositorio
- Crea una rama para realizar los cambios
- Utiliza mensajes de commit bajo la convención de Angular
- Actualiza la documentación correspondiente en VuePress junto con el código fuente
- Asegúrate de que el código pase el flujo de CI
