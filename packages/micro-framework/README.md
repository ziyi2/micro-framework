# Micro Framework

Micro Framework 是[《深入浅出微前端》](https://juejin.cn/book/7258893482318626868)小册衍生出来的一个微前端示例框架。

## 特性

- 基于 single-spa 进行封装
- 基于 iframe 进行隔离设计
- ...

## 安装

```bash
# CommonJS 库包安装
npm i micro-framework --save

# ES Module 库包安装
npm i micro-framework-es -save
```

## 依赖

- single-spa: 6.0.3
